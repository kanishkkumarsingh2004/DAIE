# Parliament Architecture

The **Parliament** architecture in DAIE brings true "Mixture-of-Agents" peer-review into the decentralized swarm, creating an incredibly rich deliberation process that dramatically improves output quality and prevents hallucinations.

Whereas a standard `Orchestrator` merely aggregates information or delegates linear tasks to specialized agents, the `Parliament` treats sub-agents as equals attempting to find the most accurate analytical answer.
## Architectural Flow

```text
┌──────────────────────────────────────────────┐
│                  USER PROMPT                 │
└──────────────────────┬───────────────────────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
  ┌────────────┐┌────────────┐┌────────────┐
  │  AGENT A   ││  AGENT B   ││  AGENT C   │
  │  (Answer)  ││  (Answer)  ││  (Answer)  │
  └──────┬─────┘└──────┬─────┘└──────┬─────┘
         │             │             │
         └─────────────┼─────────────┘
                       ▼
            ┌─────────────────────┐
            │  CROSS-PEER REVIEW  │
            │  • A reviews B & C  │
            │  • B reviews A & C  │
            │  • C reviews A & B  │
            └──────────┬──────────┘
                       │
                       ▼
            ┌─────────────────────┐
            │  SPEAKER (Synthesis)│
            │  (Selects Best Data)│
            └──────────┬──────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│           CONSENSUS OUTPUT TO USER           │
└──────────────────────────────────────────────┘
```

## How It Works

The Parliament deliberation loop follows three core steps:

1. **Initial Answer (Parallel)**: All sub-agents receive the exact same prompt and utilize their domain-specific instructions to formulate a response independently.
2. **Peer Review**: Every agent reviews the answers generated by all *other* agents in the parliament. They analyze strengths, weaknesses, and factual inaccuracies constructively. Agents do not review themselves.
3. **Synthesis**: A designated "Speaker" agent takes the original prompt, all initial answers, and all peer reviews to synthesize a single authoritative answer, smoothing out contradictions and removing hallucinated claims that didn't survive review.

## Usage

```python
from daie import Agent, AgentConfig, AgentRole
from daie.agents import Parliament
from daie.chat import ParliamentChatConfig

# 1. Define specialized agents
agents = [
    Agent(config=AgentConfig(name="Economist", role=AgentRole.DATA_ANALYST)),
    Agent(config=AgentConfig(name="Lawyer", role=AgentRole.SECURITY_AUDITOR)),
    Agent(config=AgentConfig(name="Ethicist", role=AgentRole.GENERAL_PURPOSE))
]

# 2. Assemble the Parliament
# You can designate a specific agent as the 'Speaker'. 
# By default, the first agent in the list acts as the Speaker.
parliament = Parliament(sub_agents=agents, speaker=agents[0])

# 3. Deliberate Using Interactive Chat Loop
# The chat loop naturally handles input, parses the complex JSON responses,
# deals with wait states, and performs sub-agent startup/shutdown.
config = ParliamentChatConfig(parliament=parliament)
config.run()
```

## Advanced Features & Roadmap

The current version implements a single strict round of peer review. Future developments within the Parliament class are prioritized on the DAIE Roadmap:

- **Multi-Round Review**: `max_review_rounds` configuration to allow agents to debate the reviews themselves.
- **Voting Mechanics**: An internal abstraction allowing agents to assign a 1-10 confidence score for rival answers.
- **Distributed Sub-Agents**: Integrating P2P remote nodes directly into a local Parliament to deliberate using network-wide compute.
